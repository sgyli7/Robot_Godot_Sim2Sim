# G1 自由根旋转的单位长度维护

正式设置仍是 50 Hz、每 Tick 一次积分。G1 构造时仅为自由根关节启用
`set_unit_rotation_maintenance(true)`：在已有角速度积分的四元数乘法后归一化。
不改广义坐标、速度、力矩、目标、限位、接触参数或积分次数。其他机器人和
未显式启用的关节仍执行原有乘法；关闭状态的逐位回归覆盖这个边界。

原因来自实际 native 对照：在代码 `ffd19ae` 的 ForceBased 试验中，第 47 Tick
的 `left_hand_middle_1_link` 四元数平方范数误差为 −2.044747882e−6，超过既有
2e−6 校验阈值。根部误差为 −7.525263802e−7；53 个原生刚体旋转与快照逐位
一致，失败身体与 FK 旋转也逐位一致。阈值和帧校验保留，失败并非图片或
快照转换错误。证据在 `.scratch/g1/body_quaternion_boundary_20261001_1824`。

最小回归直接调用实际 `MultibodyJoint::integrate` 和 `body_to_parent`。修复前
在第 81 Tick 达到 2.071907471e−6；修复后连续 1000 次 20 ms 积分最大误差
2.539421873e−7，并核对旋转方向和自由平移。记录在
`.scratch/g1/free_rotation_regression_20261001_1830`。

这些结果验证旋转表示的维护，不等于站立、移动、抓取或实时运行验收。
改变执行器离散后端的对照仍独立记录，不能把协议测试通过算成物理任务成功。
