# 源端 60/60 BAM 训练与独立 Idle 评估

本页说明源端站立 PPO 的长期训练与独立评估约束。MuJoCo Warp＋BAM 的训练结果只评价源端任务，不能替代目标 Rapier plant、真实接触或九技能验收。

## 固定训练与评估边界

- 物理和策略均为 60 Hz，保持 61 维观察／14 维动作合同；记录实际配置、延迟计划、源模型、依赖与 checkpoint SHA256。
- 训练可启用自动重置；评估使用独立进程、零命令、确定性推理和 `auto_reset=false`。评估不得执行 PPO 更新。
- 在查看结果前固定 checkpoint／seed 作业集合与 Idle 时长及稳定性门槛。逐一核对退出码、种子、checkpoint 与轨迹身份，不能用封套退出码代替全部作业完成。
- 配置冲突、脚本失败或不完整批次保留原始记录；修订后产生新收据。需要远程循环时，远程命令不得消费父循环 stdin。
- 保存训练曲线与独立行为轨迹。训练奖励、平均回合长度或中期单种子过关不等于最终策略通过多种子 Idle 门槛。

## 判定与晋升

正式候选须满足预先约定的全部种子与时长门槛，不能选取表现最好的一段录像或 checkpoint 代替整体结果。历史探索的最终策略未通过多种子 Idle，因而没有晋升生产 candidate；后续训练须重新建立独立证据，不能继承旧资格。

源端学习准入、训练执行、行为合格和目标 Sim2Sim 合格分别记录。任何一项缺失都不能声称九技能 ONNX 可交付。完整依赖闭包与生产许可仍依[实施交接](handoff.md)中的当前门禁执行。
